# Pronunciation Guide

The narration scripts expand most abbreviations directly. Use these readings
during audition and listening QA:

| Written term | Intended reading |
|---|---|
| Pranay Suyash | pruh-NAY soo-YUSH |
| Bengaluru | ben-guh-LOO-roo |
| Bihar Sharif | bee-HAAR shuh-REEF |
| JSON | jay-sawn |
| YAML | yam-ul |
| OCR | oh-see-are |
| PNR | pee-en-are |
| IATA | eye-AH-tuh |
| NIST | nist |
| API | ay-pee-eye |
| LLM | el-el-em |
| p95 | pee ninety-five |
| eval | ee-val |
| evals | ee-vals |
| schema | skee-muh |
| provenance | PROV-uh-nuhns |

Listen for consistent delivery of `deterministic`, `observability`,
`normalization`, `idempotency`, and `unsupported inference`.
