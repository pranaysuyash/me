## Core doctrine

- Code, screens and documents are **product evidence**, not PMF.
- A feature, persona or “market coverage” count is not demand evidence.
- No project receives meaningful build time without the next evidence gate.
- Preserve work, but remove it from the active attention budget.
- Service is acceptable when it discovers a repeatable product. Permanent bespoke work is not.
- Company/regulatory IP is governed separately from personal side projects.
