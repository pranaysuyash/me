# Review operating system

## Cadence

### Weekly, 30 minutes
- paid pipeline and revenue;
- customer evidence and supplied real inputs;
- next evidence gate for each active lane;
- tasks violating the allocation cap;
- one explicit stop/defer decision.

### Monthly, 90 minutes
- rescore active families;
- review margin, repeated use, referrals and acquisition;
- compare actual time allocation with the target;
- inspect customer-gated options for new evidence;
- update competitor/regulatory changes only where decision-relevant;
- publish a dated review under `reviews/`.

### Quarterly
- choose the next 90-day portfolio;
- archive/merge stale repos;
- refresh the portfolio case studies;
- run the independent review council;
- decide whether the third bet changes.

## Evidence ledger schema

- date;
- project/family;
- evidence tier before/after;
- source: customer, user, revenue, benchmark, repo, market, regulatory;
- fact observed;
- interpretation;
- decision changed;
- next test;
- owner and due date.

## Decision states

- FOCUS NOW
- BUILD ONLY AS PAID PILOT
- CUSTOMER-GATED
- PORTFOLIO / CAREER
- MAINTAIN
- MERGE / CONSOLIDATE
- PAUSE
- ARCHIVE / READ-ONLY
- COMPANY / SEPARATE GOVERNANCE

## Review triggers outside cadence

Reopen a project when any of these occurs:
- a qualified buyer asks for it and supplies data;
- a paid pilot or partner becomes available;
- organic usage crosses a predeclared threshold;
- a regulation or platform change materially improves the wedge;
- a core dependency becomes cheaper or reliable enough to change economics;
- a focused project produces a reusable component that removes the prior blocker.

Do not reopen because a new model, framework or design trend appears.

## Dashboard KPIs

- active commercial lanes: maximum 3;
- percentage of time on focused lanes: target ≥95%;
- paid diagnostics/pilots;
- recurring customers;
- qualified conversations;
- supplied real datasets/workflows;
- gross margin and human minutes per delivery;
- repeated use within 30 days;
- references/referrals;
- projects merged/paused/archived;
- evidence-tier movement.
